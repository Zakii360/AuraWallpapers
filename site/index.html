01 / Built around the wallpaper

Not a video player.
A real runtime.

Wallpapers are ordinary web packages. AuraWallpapers loads them into a dedicated runtime and layers host-controlled effects on top, so the wallpaper itself stays simple and portable.

01

Web-native wallpapers

Build backgrounds with HTML, CSS and JavaScript. The package manifest defines the entry point and preview.

02

Layered effects

Rain, snow, fog, particles, blur, camera drift, color grading and vignette can be changed at runtime.

03

Multi-monitor control

Manage wallpaper instances per display, with clone-style behavior available by applying the same wallpaper to each monitor.

04

Performance aware

A dedicated performance layer can watch fullscreen applications and protect system resources when needed.

02 / Under the hood

Small pieces.
Clear boundaries.

The project separates the Electron shell from the platform-agnostic core. Desktop integration lives at the edge, while wallpaper management, settings and effects remain independently testable.
